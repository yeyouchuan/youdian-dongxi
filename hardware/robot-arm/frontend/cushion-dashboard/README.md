# 坐姿报告 · SmartCushion 智能坐垫前端 Demo

智能坐垫项目的手机端报告界面 demo：坐姿健康打分、AI 日报、姿态分布时间轴、生物特征数据。
当前为**纯前端 + 模拟数据**，无任何后端依赖，拿到代码即可运行。

## 跑起来（3 步）

```bash
npm install        # 1. 安装依赖（需要 Node.js 20+）
npm run dev        # 2. 启动开发服务器，浏览器打开终端里显示的地址
npm run build      # 3. （可选）构建生产版本到 dist/
```

## 项目结构

```
src/
├── data/report.ts          # 唯一数据源：一天的模拟数据都在这，改文案/数字从这里入手
├── components/
│   ├── PhoneFrame.tsx      # 手机机身边框 + 假 iOS 状态栏
│   ├── ScoreGauge.tsx      # 半圆刻度仪表盘（打分主视觉）
│   └── PostureBar.tsx      # 姿态分布堆叠时间轴
├── sections/               # 页面各卡片：打分卡 / AI 总结 / 姿态分布 / 生物特征 / 标签 / 底部 Tab
└── App.tsx                 # 页面组装
showcase/                   # 产品展示图集 + A4 产品介绍 PDF（营销物料，非代码）
```

## 润色时请守住的设计约定（话术准绳）

1. **全文禁止出现「情绪」二字**——疲劳/压力类指标只能叫「状态指数」。
2. 心率相关区域必须保留「静坐状态下更准确」的提示小字（毫米波雷达在人活动时测不准，这是诚实设计，不是缺陷）。
3. 身份识别低置信度时显示「未知访客」，**永远不猜测一个可能错误的名字**。
4. 页脚/物料中保留「演示数据 · 非医疗诊断设备」声明。
5. 打分必须透明：每一分扣在哪都要能展示明细（当前：二郎腿超时 −8、连续久坐 −9、午后状态指数走低 −5）。

## 设计参考

整体风格对标高端睡眠报告 App（深色底 #0a0a0c、卡片 #141418、大圆角、克制的青/绿点缀）。
`showcase/` 里的 5 张展示图和 `坐姿报告-产品介绍.pdf` 是当前界面的定妆照，可作为润色基准。

## 数据说明

`src/data/report.ts` 中的数字彼此自洽（如：坐姿总时长 432 分钟 = 7小时12分，端正度 82% 由时间轴真实算出）。
改数据时请保持这种自洽性，评委可能会当场验算。
